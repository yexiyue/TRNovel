# TRNovel 0.19.0 发布记录

状态：crates.io 已发布，安装包发行因默认 macos-14 构建机不可用中止；按用户要求保留 0.19.0 版本和标签，以手动触发流程恢复安装包分发，不重复发布 crate。用户已授权提交、推送及正式发布。版本清单为 0.19.0，parse-book-source 保持 0.7.0。下方验证记录来自发布准备阶段，实际发布结果以远端流水线及注册表为准。

## 用户可见发布说明

> **听书功能正在大规模重构，当前暂不保证稳定性与可用性。** 请等待重构完成后再将其用于日常听书。普通阅读可独立使用，无需安装 Talechime。

本次主要改善阅读与操作体验：

- 全局、阅读、听书设置使用统一顶部标签和可点击控件，补齐 hover 与键盘导航。
- 目录宽度可连续调整，拖动正文左边框即可设置；自动保存，调整与窄窗口切换保留阅读位置。
- 网络书籍详情的阅读按钮固定在底部居中，整框可点击，支持继续阅读。
- 统一轻量悬停提示，去掉设置底部重复说明；路径、配置文件和项目外链支持点击或 Enter 打开。
- 修复阅读偏好保存、标题显示、缩进裁切、翻页留白和设置返回/滚动问题。
- 源码构建可关闭 network feature，只保留本地阅读能力。

**配置变化：** 目录占宽使用 `[reader].toc_width_percent`，默认 50%。旧 `toc_ratio` 不再读取，升级后可重新拖动调整。外观及其它偏好保持现有保存路径。

感谢 PR #82 贡献者 Aztand，以及持续反馈阅读体验的用户。

## 发布范围与步骤

应用标签应为 `trnovel-v0.19.0`，只发布 TRNovel，排除 `parse-book-source`。阅读器仍为统一分发，不恢复 basic 或捆绑 Talechime。

当前 `.github/scripts/release.sh` 会执行 version / hook / commit / tag / push，不能用于预览。候选已提前修改版本；真正发布时应先提交功能和文档，再按现有 cargo-release 子命令完成 hook、release commit、应用 tag 和 push，避免重复 bump。自动 hook 会重建 CHANGELOG，发布前须与本文及 README 的听书警告核对。

本机检查只代表候选准备完成。GitHub Release、npm、Homebrew、crates.io 是否发布及各平台安装验收须在实际 tag 推送后分别确认，不能用 plan 或打包成功替代。
