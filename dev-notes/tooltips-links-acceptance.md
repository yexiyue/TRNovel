# 统一提示与设置链接验收

日期：2026-11-16。基线 `82c3337`。本次按用户要求仅保留本地修改，不提交、不推送。

## 实现

- 共享 Tooltip 提供弱色细边框、左右留白、快捷键强调和终端内自适应位置。普通提示延迟 300ms；键盘、点击和滚动后保持收起，实际移动鼠标才重新显示，避免输入时覆盖控件。只观察输入，不消费原事件。目录拖拽即时反馈复用该组件。
- 菜单悬停只显示打开方式，展开后在菜单底边显示导航说明。全局、阅读、听书设置与配色编辑器移除常驻重复 detail/帮助行。配色输入中的值、打开/保存错误与真实听书状态保留；截断的只读值可悬停看全文。
- 数据页改为“本地文件与目录”，链接包括配置文件、数据/缓存目录、上游仓库和使用文档。链接有强调色、下划线及 hover；标签只聚焦，值单击或 Enter 打开，左右键无动作。路径显示使用 ~ 和中间省略，保留文件名；外链用 ↗ 标识。
- 文件、目录、网址使用具名目标类型，展示字符串不用于启动。系统调用在阻塞任务中执行并反馈错误；macOS 配置文件用 open -R 定位，目录/网址用默认程序。Windows/Linux 分支本次没有实机验收。

## 验证

通过全功能 workspace lib/tests/examples、严格 Clippy、格式、严格 rustdoc、无默认功能与仅 TTS 的 cargo check、文档站构建及严格 OpenSpec 校验。

真实 PTY 运行 settings_tabs、settings_surfaces、reader_panes、tooltips_links。验证延迟与隐藏、快捷键样式、窄窗口、非重复底部说明、标签/控件命中、链接单击与 Enter、左右键不打开、失败与重试、原有阅读锚点与拖拽取消。

链接测试通过隔离 HOME 和 PATH 中记录版 macOS open 检查真实 UI 触发的 argv：配置文件包含 -R，目录和网址使用原始目标，不包含 ~、省略号或 ↗。注入启动失败以验证错误与成功重试；未实际打开用户的 Finder 或浏览器。

测试减少固定说明后要用更矮窗口验证滚动，不能依赖原来 footer 占用的高度。PTY teardown 关闭 core dump，并给进程回收设置上限，避免异常子进程使验收无限阻塞。
