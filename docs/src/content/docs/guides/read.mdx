无论本地还是网络小说,进入后的阅读界面是一致的:左侧是章节目录,右侧是正文,底部显示行数与进度。阅读界面有两种模式,用 `Tab` 切换。

![阅读与翻页](../../../assets/guides/read.gif)

## 章节选择模式

打开小说默认进入此模式,焦点在左侧目录:

- `↑/↓`(或 `k/j`)选择章节,回车进入该章正文;
- 按 `s` 搜索章节,支持以 `$` 开头输入数字按**序号**跳转(如 `$120`);
- 按 `Tab` 切换到阅读模式。

## 阅读模式

焦点在右侧正文,沉浸式阅读:

- `↑/↓`(或 `k/j`)向上 / 向下逐行滚动,`PageUp / PageDown`(或 `Ctrl+B / Ctrl+F`)整页翻动;
- `←/→`(或 `h/l`)切换上一章 / 下一章;
- `V` 隐藏 / 显示章节标题,`Tab` 返回章节选择模式;
- `O` 打开阅读设置,`T` 打开[听书设置](/TRNovel/guides/tts/),`P` 播放 / 暂停朗读。

滚动与翻页读到**章末**时不会直接跳章:底部先提示「已到本章末尾」,再按一次才进入下一章,防止最后一行没看完手滑跳走。章首向上同理。

以上按键均可在 `~/.novel/keybindings.toml` 中[自定义](/TRNovel/guides/keybindings/)(v0.15.0+)。

<Aside type="tip">
记不住键位?任意页面按 `i` 即可呼出当前模式支持的全部快捷键。
</Aside>

![快捷键面板](../../../assets/guides/shortcuts.gif)

## 当前章节正文搜索

阅读模式按 `s` 打开底部搜索栏，输入关键词后按 `Enter` 提交。搜索区分大小写，按字面量匹配当前章节，全部命中会高亮，当前结果额外加粗。底部显示结果数量，没有匹配时显示“未找到”。

- `n` / `N` 跳到下一个 / 上一个结果，首尾循环。
- 编辑时按 `Esc` 取消输入，保留原搜索；阅读时按 `Esc` 清除搜索。提交空关键词也会清除。
- 输入期间不移动正文或改变已提交结果；手动滚动后不会自动跳回结果。
- 换章或返回目录模式时清除搜索。加载、设置和帮助浮层期间不能搜索。
- TTS 继续朗读；搜索与朗读高亮重叠时优先显示搜索，清除后恢复朗读高亮。

只搜索当前已加载章节，不下载其他章节。暂不支持全书搜索、正则或跨原始段落匹配。以上四个搜索操作也支持[自定义快捷键](/TRNovel/guides/keybindings/)。

## 阅读设置

阅读模式按 `O` 打开阅读设置面板,`↑/↓` 选择条目、`←/→` 调整,改动即时生效并自动保存到 `~/.novel/reader-display.json`:

![阅读设置](../../../assets/guides/reader-settings.gif)

| 设置项 | 说明 |
|--------|------|
| 翻页重叠 | 整页翻动时,保留上一屏末尾的若干行作为新一屏的开头,翻页后不丢失视觉锚点。默认 `2` 行,可调 `0`~`10`;设为 `0` 即整屏平移。面板会同时显示当前终端下每页实际滚动多少行。 |
| 显示标题 | 章节标题与底部提示的显隐,等同于按 `V`。 |
| 段落间距 | 是否在段落之间插入一个空行。小说正文多以单个换行分段,不插时段落首尾相接、读起来较紧凑;插入后段落分明,但一屏能看的正文行数会少近一半。默认**关闭**。 |

<Aside type="note">
开启翻页重叠后,读到章节末尾时正文下方会自然留白——这是为了让每次翻页的滚动距离**完全一致**。逐行滚动(`↑/↓`)不受影响,仍然滚到最后一行贴屏幕底部为止。
</Aside>

## 进度与退出

阅读进度会**自动保存**,下次打开同一本书自动续读。底部状态栏显示当前行数与百分比。在任意界面按 `q` 或 `Ctrl+C` 退出 TRNovel,退出前会落盘最新进度到[历史记录](/TRNovel/guides/history/)。

## 跟随朗读

听书版默认开启“跟随朗读”。实际播放的片段进入窗口底部两行或移出窗口时，阅读器会滚动，将片段起始位置放在上方约三分之一处；片段仍在安全区域时不移动。无需开启逐句对齐。

手动滚动、翻页、跳到开头/结尾或进入正文搜索后，底栏显示“自由浏览”，窗口保持在手动位置。按 `f` 回到当前朗读位置并恢复跟随；自定义键位后以帮助和底栏显示的键为准。暂停或缓冲期间也可以用该操作定位，但不会启动播放。

缓冲、暂停、搜索输入或面板打开期间不自动滚动。自动续章和音色切换保留自由浏览状态，打开另一本文本后重新按保存的设置初始化。阅读设置中的“跟随朗读”控制保存为 `followTts`；旧配置缺少该字段时默认开启，基础版隐藏该设置。
