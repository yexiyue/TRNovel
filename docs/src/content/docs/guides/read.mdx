无论本地还是网络小说,进入后的阅读界面是一致的:左侧是章节目录,右侧是正文,底部显示行数与进度。阅读界面有两种模式,用 `Tab` 切换。

![阅读与翻页](../../../assets/guides/read.gif)

## 章节选择模式

打开小说默认进入此模式,焦点在左侧目录:

- `↑/↓`(或 `k/j`)选择章节,回车进入该章正文;
- 按 `s` 搜索章节,支持以 `$` 开头输入数字按**序号**跳转(如 `$120`);
- 按 `Tab` 切换到阅读模式。

## 阅读模式

焦点在右侧正文,沉浸式阅读:

- `↑/↓`(或 `k/j`)向上 / 向下逐行滚动,`PageUp / PageDown`(或 `Ctrl+B / Ctrl+F`)整页翻动;
- `←/→`(或 `h/l`)切换上一章 / 下一章;
- `V` 隐藏 / 显示章节标题,`Tab` 返回章节选择模式;
- `O` 打开阅读设置,`T` 打开[听书设置](/TRNovel/guides/tts/),`P` 播放 / 暂停朗读。

滚动与翻页读到**章末**时不会直接跳章:底部先提示「已到本章末尾」,再按一次才进入下一章,防止最后一行没看完手滑跳走。章首向上同理。

以上按键均可在 `~/.novel/keybindings.toml` 中[自定义](/TRNovel/guides/keybindings/)(v0.15.0+)。

<Aside type="tip">
记不住键位?任意页面按 `i` 即可呼出当前模式支持的全部快捷键。
</Aside>

![快捷键面板](../../../assets/guides/shortcuts.gif)

## 阅读设置

阅读模式按 `O` 打开阅读设置面板,`↑/↓` 选择条目、`←/→` 调整,改动即时生效并自动保存到 `~/.novel/reader-display.json`:

| 设置项 | 说明 |
|--------|------|
| 翻页重叠 | 整页翻动时,保留上一屏末尾的若干行作为新一屏的开头,翻页后不丢失视觉锚点。默认 `2` 行,可调 `0`~`10`;设为 `0` 即整屏平移。面板会同时显示当前终端下每页实际滚动多少行。 |
| 显示标题 | 章节标题与底部提示的显隐,等同于按 `V`。 |

<Aside type="note">
开启翻页重叠后,读到章节末尾时正文下方会自然留白——这是为了让每次翻页的滚动距离**完全一致**。逐行滚动(`↑/↓`)不受影响,仍然滚到最后一行贴屏幕底部为止。
</Aside>

## 进度与退出

阅读进度会**自动保存**,下次打开同一本书自动续读。底部状态栏显示当前行数与百分比。在任意界面按 `q` 或 `Ctrl+C` 退出 TRNovel,退出前会落盘最新进度到[历史记录](/TRNovel/guides/history/)。
