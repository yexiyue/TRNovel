# Design

缓冲控制只依赖实际播放器的原始音频时间位置、累计入队时长、用户暂停标志和生成结束状态。初始暂停 sink，达到目标再恢复；播放耗尽时暂停并提高下一次恢复目标，避免收到一个小块就恢复。播放倍率共享到控制器，目标以墙钟秒换算，最大 20 秒原始音频，低于预取预算以避免背压死锁。

缓冲期间不发布 SegmentStarted，也不提交尚未播放的检查点。用户 resume 不能绕过缓冲；用户 pause 时继续有界预取，但自动恢复不能覆盖它。正常 EOF 不足目标时排空剩余音频；失败仍停止且不重播。

协议 v4 尚未发布，与本轮 Qwen 变更一起增加 Buffering 与 BufferStatus，reader/worker 配套升级。每秒或状态变化报告一次余量与耗尽次数；会话 ID 继续隔离旧状态。Qwen stderr 诊断仅在 NOVEL_TTS_DIAGNOSTICS=1 时启用，并单独记录生成与通道等待，避免把背压当作模型变慢。音频块粒度维持十帧，先记录耗时与验证缓冲收益。
