# 设计

用途：快速调整阅读与外观，兼顾键盘和鼠标。沿用当前终端主题与等宽字体；主要色仅用于当前标签、焦点标记和控件反馈，不整行铺满强调色。

顶部顺序：阅读、外观、键位、数据、关于。表单最大 88 列，阅读项按排版、翻页、界面和听书分组。顶栏与内容分别是复合焦点区域：Tab/Shift+Tab 切换焦点区域；标签焦点下左右切换标签；表单内上下选项，左右调整，Space/Enter 激活。Esc 先关闭选择浮层，否则返回。

鼠标移动只显示 hover，不选标签、不移动键盘焦点、不改配置。点击标签立即切页；点击值控件直接操作，点击标签文字只聚焦该项。数值的减/加按钮有明确命中范围，边界禁用；枚举使用独占层选择器。滚轮与拖动滚动条移动表单视口，键盘焦点变化时自动显露目标行。

布局与点击复用同一控件几何。复用 ratatui-kit 的 hover、scrollbar、Modal 和输入层，不引入 UI 依赖。原文、阅读分页和听书引擎不在本次改动范围。
