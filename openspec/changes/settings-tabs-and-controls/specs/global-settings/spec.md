## ADDED Requirements

### Requirement: 顶部标签导航
五个同级分组 MUST 作为顶部标签呈现，当前标签、键盘焦点和鼠标 hover MUST 可区分。标签可单击切换，Tab/Shift+Tab MUST 在标签栏与表单之间移动焦点；标签焦点下方向键切换当前分组。重新访问保留分组与条目位置。

#### Scenario: 标签与表单分别导航
- **WHEN** 用户在标签栏悬停、点击或使用方向键
- **THEN** 悬停只改变反馈，点击或方向键切换当前分组，Tab 将焦点移入表单

### Requirement: 控件直接操作
布尔值 MUST 使用可点击开关，数值 MUST 提供可见减/加按钮，枚举 MUST 能打开选择器，外观页 MUST 可直接调整背景、顶部栏和退出确认。设置项标签文字点击只移动焦点，MUST NOT 使用不可见的左右半行调整协议。不可调整的数值边界 MUST 有禁用反馈。

#### Scenario: 单击明确的控件
- **WHEN** 用户点击开关、数值加号或枚举值
- **THEN** 分别切换布尔值、增加一档或打开选择器，不需要先点整行聚焦

### Requirement: 悬停与滚动
Hover MUST 仅改变视觉反馈，不改变配置或键盘焦点。表单 MUST 在矮窗口可滚动，键盘移动 MUST 显露选中项；点击范围 MUST 与实际绘制范围一致，不命中裁剪行、间距或边框，只读值不得调值。枚举选择器 MUST 支持鼠标、键盘与 Esc 取消，并隔离背景输入。

#### Scenario: 矮窗口访问末项
- **WHEN** 窗口高度不足且用户按 End、滚动滚轮或拖动滚动条
- **THEN** 末尾设置项可见，点击仅操作其实际绘制范围，悬停不改变值或键盘焦点

### Requirement: 配置持久化
阅读与外观调整 MUST 继续立即生效并使用既有 config.toml 保存路径。切页、退出及主题页往返 MUST NOT 丢失最近一次修改。键位、目录和构建信息 MUST 如实展示，提示开关 MUST 继续控制操作说明。

#### Scenario: 调整后立即退出
- **WHEN** 用户修改阅读项并在防抖间隔内退出，或切到主题页再返回
- **THEN** 最后一次修改保存在 config.toml 中，返回设置页后恢复分组和条目位置
