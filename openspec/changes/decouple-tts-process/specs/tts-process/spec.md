# Spec Delta

## Purpose

定义可独立使用的听书程序，以及阅读器通过标准输入输出调用该程序的行为契约，明确交互模式、兼容协商、进程生命周期和故障隔离，使调用方无需链接模型或音频播放实现。

## ADDED Requirements

### Requirement: 独立文本文件 CLI
听书程序 SHALL 独立朗读 UTF-8 文本文件，显示实际状态并提供暂停、继续、停止和退出控制；CLI 与协议模式 SHALL 使用相同合成与播放语义。

#### Scenario: 独立朗读与控制
- **WHEN** 用户直接启动听书 CLI 并提供有效文本文件
- **THEN** 无需运行 TRNovel 即可朗读，并能暂停、继续、停止及退出

#### Scenario: 无效文件
- **WHEN** 文件无法读取或不是支持的文本编码
- **THEN** CLI 给出具体错误和非零退出状态，不开始播放

### Requirement: 版本化 JSON Lines 协议
协议模式 SHALL 通过 stdin/stdout 传输 UTF-8 JSON Lines，协商协议主版本并关联请求响应；异步会话事件 SHALL 带进程实例、会话标识和有序序号。日志 SHALL 写入 stderr，音频 SHALL 在听书进程播放；协议模式 MUST NOT 接管终端按键。

#### Scenario: 兼容连接
- **WHEN** 阅读器与兼容程序完成握手并提交播放命令
- **THEN** 阅读器收到关联响应及带会话标识的播放事件，stdout 每行均为协议消息

#### Scenario: 不兼容与非法输入
- **WHEN** 协议主版本不兼容、消息非法或超出约定大小限制
- **THEN** 程序返回可识别错误或结束连接，不启动对应播放，阅读器显示原因

#### Scenario: 正文包含换行
- **WHEN** 提交含换行和中文的正文
- **THEN** 正文在消息内保持原样，消息仍由独立 JSON 行界定

### Requirement: 按需启动和程序发现
阅读器 SHALL 支持明确配置听书程序路径，并优先于同目录和 PATH 查找。缺少程序、显式路径无效或握手失败 SHALL 只使听书不可用，MUST NOT 阻塞普通阅读。

#### Scenario: 安装后的首次听书
- **WHEN** 用户首次执行需要听书状态或播放的操作且同目录有兼容程序
- **THEN** 阅读器启动程序并连接；仅查看状态或设置不自动下载模型或播放

#### Scenario: 明确路径不可用
- **WHEN** 用户明确配置的程序路径无效
- **THEN** 提示该路径错误，不静默换用其他程序，正文阅读仍可用

### Requirement: 子进程复用与清理
阅读器 SHALL 跨章节复用已启动的听书进程；停止播放 SHALL 保留模型，主动释放资源及阅读器退出 SHALL 关闭并回收子进程。输入通道 EOF SHALL 使程序停播、保存检查点并退出。关闭和握手 SHALL 有超时，失败后 MUST NOT 无限自动重启。

#### Scenario: 跨章复用
- **WHEN** 当前章节正常完成并开始下一章
- **THEN** 同一子进程继续处理，不因切章重新启动程序或加载已保留模型

#### Scenario: 退出和父进程断开
- **WHEN** 阅读器正常退出或协议输入通道断开
- **THEN** 子进程终止播放及后台任务，释放资源并退出；正常退出超时后阅读器终止并回收它

#### Scenario: 程序崩溃
- **WHEN** 听书程序异常退出
- **THEN** 阅读器报告故障并保留恢复信息，普通阅读可继续，等待用户重试
