# Spec Delta

## MODIFIED Requirements

### Requirement: 与听书面板互斥
启用听书 UI 的构建中，阅读设置浮层与听书设置浮层 SHALL 互斥显示，打开其一 SHALL 关闭另一个。基础构建 SHALL 独立提供阅读设置浮层，不依赖听书组件。所有构建中浮层开启期间背景正文 MUST NOT 响应滚动键；浮层 MUST NOT 阻断其下层的入口键处理，否则将无法关闭。

#### Scenario: 打开阅读设置关闭听书面板
- **WHEN** 启用听书 UI 的构建中听书面板开启时用户按下 `o`
- **THEN** 听书面板关闭，阅读设置浮层打开，两者不叠加渲染

#### Scenario: 面板开启时正文不滚动
- **WHEN** 阅读设置浮层开启，用户按下向下滚动键
- **THEN** 事件由面板处理，背景正文位置不变

#### Scenario: 面板可被关闭
- **WHEN** 阅读设置浮层开启，用户按下入口键或切换模式键
- **THEN** 事件仍能到达页面级处理器，面板正常关闭或模式正常切换

#### Scenario: 基础版阅读设置
- **WHEN** 未编译听书 UI 的阅读器中用户按下 `o`
- **THEN** 阅读设置正常开合，导航、调整和持久化保持可用，无需听书面板或程序
