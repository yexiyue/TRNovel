## ADDED Requirements

### Requirement: 统一提示
工具栏与设置字段 MUST 使用统一的有边框、带留白、就近定位的非阻塞提示，约 300ms 后出现，离开/换目标/卸载 MUST 隐藏或取消旧提示，窄窗口 MUST 保持在屏幕内。拖拽反馈 MUST 即时更新并使用同一视觉组件。
#### Scenario: 悬停菜单入口
- **WHEN** 用户悬停菜单按钮
- **THEN** 只提示打开方式，完整导航说明仅在菜单展开后显示，不重复菜单名或挤在正文边框上

### Requirement: 设置说明去重
全局、阅读与听书设置 MUST 移除固定底部重复说明，通过共享字段提示展示必要说明；全局设置 MUST 不重复显示通用页底操作提示。错误及听书状态 MUST 保留，帮助入口 MUST 仍可访问。
#### Scenario: 查看本地路径
- **WHEN** 用户进入数据标签
- **THEN** 路径只显示在相应链接中，底部不重复显示选中路径

### Requirement: 可操作链接
配置文件、数据/缓存目录及项目网址 MUST 为带下划线的链接，值单击与 Enter MUST 打开相同原始目标，标签仅聚焦、左右键不得打开。目录 MUST 用文件管理器打开，配置文件 MUST 定位或打开父目录，网址 MUST 使用默认浏览器。路径显示 MUST 保留末端文件名，错误 MUST 明确反馈，不得因打开而修改配置。
#### Scenario: 激活及失败
- **WHEN** 用户单击链接或按 Enter，系统启动失败
- **THEN** UI 保持响应并显示错误，成功重试后错误清除
