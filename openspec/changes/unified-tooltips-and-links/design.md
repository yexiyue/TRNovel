# 设计

共享 Tooltip 负责细边框、留白、自动换行、终端边界和非阻塞浮层；use_tooltip 用 owner 管理悬停来源，移开/卸载只清除自身提示。工具栏及 SettingsForm 的说明约 300ms 后出现，换目标取消旧计时，键盘/点击/滚动后保持隐藏至再次移动指针，菜单打开时隐藏。拖动宽度的即时反馈复用视觉组件，不延迟。提示不参与正文或表单高度。

全局、阅读与听书设置删除固定 detail 行；共享表单只对有效且不重复值的 detail 给出就近悬停说明。全局设置隐藏通用页底快捷键提示，帮助入口保持；打开/保存失败仍显示错误。听书的真实状态、声音应用说明和模型提醒保留。

Control::Link 明确链接视觉与精确命中；标签只聚焦，值单击或 Enter 激活，左右调整无效。Link 枚举和 Target 区分网址、目录、文件，显示采用 ~ 和保留后缀的中间截断，打开使用原始目标。阻塞系统调用放到 spawn_blocking，错误返回设置页。macOS open -R 定位配置文件，Windows Explorer 定位，其他桌面打开父目录；网址/目录使用系统默认程序。应用不拼接 shell 命令，系统调用使用独立参数；跨平台默认打开由 open 库处理；不创建缺失目录。

macOS PTY 使用 PATH 中的记录版 open，检查真实 UI 分发的 argv 与失败结果，不打开用户 Finder/浏览器。Windows/Linux 分支本次没有实机验证。
