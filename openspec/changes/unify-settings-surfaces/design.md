# 设计

沿用现有主题与终端字体。共用轻量分组行、显式数值加减、直接开关及枚举选择器。hover 不改变值或键盘焦点；滚轮浏览视口，键盘操作显露焦点。绘制与命中使用同一当帧几何。

全局设置、阅读弹窗、听书面板共用 SettingsForm / SettingsTabs / SettingsPicker。阅读弹窗提供排版、翻页、界面、听书（按 feature）标签，继续由阅读页保存偏好。听书提供播放、声音、高级标签，保持 ConfigPatch、模型/音色筛选、staged sound、应用重播和取消准备的原有业务语义。配色列表保留已有 hover，补全自定义编辑器的鼠标字段、基准主题、色块和保存/取消入口。

独占浮层不让鼠标、滚轮或 Esc 穿透；回调跨局部 hover 重绘稳定保存。配置格式与工作进程协议不变。


维护性复查：阅读字段身份使用具名 Setting，Group 只用于分组；视觉行索引仅用于焦点。共享控件拆成 tabs/form/picker/button，纯 navigation 统一按键转换。稳定回调提升到通用 hook；阅读偏好保存也共用 hook，在同一进程写入门内读取最新 atom，避免游离旧快照覆盖最终值。配色草稿单独管理显式覆盖与继承，字段行提供任意颜色预览。配置格式与现有保存路径不变。
